# Statement extraction guidance

A statement is a periodic account summary.

- vendor: the issuer.
- customer: the account holder.
- document_number: statement reference.
- account_number: the account.
- document_date: statement period end / issue date.
- due_date: payment due if any.
- subtotal, total: balance and outstanding.
- line_items: charges / credits as rows.

Return JSON only.
